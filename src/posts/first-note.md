I am going to write things down here. Mostly for me - a place to put what I
worked out, so that next time I need it I can look it up instead of working it
out again.

Keeping it public is deliberate, and not because anyone is reading. It is
because the version I would write for myself is the version where I skip the
part I do not understand yet.

Let's see how long this lasts.
